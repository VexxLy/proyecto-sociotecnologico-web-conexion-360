# Proyecto Sociotecnológico: Fundación Rutas del Araguaney

Página web del caso de estudio del equipo **Conexión 360** (UNETI, PNF en Ingeniería en Informática, Trayecto I).

Página publicada: https://vexxly.github.io/proyecto-sociotecnologico-web-conexion-360/

## Cómo editar

Todo está en `index.html`. Los datos que más se cambian (integrantes, enlaces del Drive, reflexiones, fechas) están al inicio del bloque `<script>`, en la sección "1. DATOS QUE EL EQUIPO DEBE EDITAR".

Para cambiar algo desde el navegador: abre `index.html`, pulsa el lápiz (Edit this file), haz el cambio y pulsa **Commit changes**. La página se actualiza en uno o dos minutos.
